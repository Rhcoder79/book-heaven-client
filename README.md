# 📚 Book Heaven - Full Stack Book Management System

**Book Heaven** is a modern book management application where users can discover new books, manage their personal library, and share thoughts through an interactive comment system. The platform is designed to be user-friendly, secure, and fully responsive.

## ✨ Key Features

1.  **Full CRUD Operations:** Authenticated users can easily **Create, Read, Update, and Delete** book entries.
2.  **Interactive Comment System:** Logged-in users can post reviews and comments on book details pages, which update in real-time.
3.  **Dynamic Rating Sorting:** Users can sort the book collection based on ratings (High to Low or Low to High) for better discovery.
4.  **Secure Authentication:** Integrated with **Firebase Auth** to ensure that sensitive actions (like adding or editing books) are restricted to registered users only.
5.  **Fully Responsive Design:** Built with **Tailwind CSS** and **DaisyUI**, providing a seamless experience across mobile, tablet, and desktop devices.

---

## 🛠 Technologies Used

* **Frontend:** React.js, React Router, Tailwind CSS, DaisyUI
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Authentication:** Firebase Auth
* **Libraries:** Axios, SweetAlert2, Date-fns

## ⚙️ Local Setup Instructions

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/your-username/book-heaven.git](https://github.com/your-username/book-heaven.git)
    ```
2.  **Install dependencies:**
    ```bash
    npm install
    ```
3.  **Setup Environment Variables:** Create a `.env` file and add your Firebase and MongoDB credentials.
4.  **Run the project:**
    ```bash
    npm run dev
    ```
